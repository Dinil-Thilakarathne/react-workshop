# Modern Web Development with React

Welcome to the React Workshop! This repository contains the code and resources for our session on modern web development, focusing on the shift from imperative DOM manipulation to declarative React components.

## Slide deck

[View Slide Deck](https://www.figma.com/deck/kNcEQyPFA1dmYyXyxBtRgM/React-workshop?node-id=1-311&t=4stTFAlhREdXPTBR-1)

## 📂 Project Structure

- **`/starter`**: The "Old Way" (Imperative).
  - Manipulates the DOM manually using `document.getElementById` and `addEventListener`.
  - Demonstrates the complexity and fragility of keeping state in sync with the UI manually.

- **`/final`**: The "React Way" (Declarative).
  - Uses **React Components** for reusability and isolation.
  - Manages data with **State** (`useState`).
  - Styled with **Tailwind CSS**.
  - Built on **Next.js**.

## 🚀 Key Technologies

- **Modern JavaScript**: `const`/`let`, Arrow Functions, Destructuring, Array `.map()`.
- **React**:
  - **JSX**: Writing JavaScript within HTML.
  - **Virtual DOM**: Efficient UI updates.
  - **Hooks**: `useState` for memory, `useEffect` for synchronization.
- **Tailwind CSS**: Utility-first CSS for rapid styling.
- **Next.js**: The React framework for production (Routing, SEO, Optimization).

## 🛠️ Getting Started

1.  Explore the `/starter` directory to see the imperative approach.
2.  Move to the `/final` directory to explore the modern React implementation.
